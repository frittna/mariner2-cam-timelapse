with Pi-CSI camera support 1296x960 30fps + further measures for secure operation also online

Github code  : Github code: https://github.com/frittna/Mariner-2-Cam
Built on code: Github code: https://github.com/amd989/mariner

My printer: Elegoo Mars 3
NOTE: New Chitubox .ctb files are encrypted in such a way that Mariner is quite slow on only one core when loading the preview image. (fixed in timelapse-video release)
Workaround: resave the .ctb slice file with UVtools, therefore sometimes distorted display of the preview image

###### PREPARATION: (Raspberry Pi Imager Tool for Windows)
On the Zero 2 W, Trixie 64-bit OS-Lite works.;
Power it with a strong external 1.5-2A power supply since it is definitely supplied too weakly on the printer. Absolutely avoid the "double-power" problem!!

##START##
When creating the SD card (8GB or more) with Pi Imager and Windows, set SSH access and set WLAN settings already.
Create image -> insert SD card -> use OTG-USB port (the inner USB port of the 2 ports) and power-on..wait..~4 min
Meanwhile determine the IP of the Pi and best assign it fixed (static IP reservation on the internet router-router)
Then connect via console and SSH with PUTTY or other tools.
Now still with IP and port 22, later when security is ramped up with firewall and VPN via port 50222 !

# Allows the frontend to fully switch off camera load on the Pi
@app.route('/api/camera/<action>', methods=['POST'])
@csrf.exempt
def control_camera(action: str):
    if action == 'stop':
        import subprocess
        subprocess.run(["sudo", "systemctl", "stop", "mediamtx"])
        return {"status": "Camera stopped, CPU relieved"}, 200
    elif action == 'start':
        import subprocess
        subprocess.run(["sudo", "systemctl", "start", "mediamtx"])
        return {"status": "Camera started"}, 200
    return {"error": "Invalid action"}, 400
EOF

# 1. Install and secure firewall:

sudo ufw default deny incoming

# Ports for MediaMTX (stream & control):

sudo ufw allow 8554/tcp                             # MediaMTX RTSP
sudo ufw allow 8189/udp				    # WebRTC MediaMTX 
sudo ufw allow 8189/tcp				    # WebUTC MediaMTX
sudo ufw allow in on tailscale0			    # VPN
sudo ufw allow 50222/tcp			    # SSH port
sudo ufw allow from 192.168.0.0/24 to any app Samba # samba-sharing
# Allow system access ONLY from local network (192.168.0.X):
sudo ufw allow from 192.168.0.0/24 to any port 50222 # New SSH port
sudo ufw allow from 192.168.0.0/24 to any port 5000  #  Mariner web browser
sudo ufw allow from 192.168.0.0/24 to any port 10000 # Webmin browser
